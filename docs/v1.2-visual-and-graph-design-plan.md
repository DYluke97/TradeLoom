# TradeLoom v1.2 联合设计方案：全局投研终端质感（大项 B）× 全画幅沉浸星图（新版大项 C）

> 本方案严格基于当前代码架构设计（不改动后端业务与数据接口），重点解决“第一眼偏工程后台、全站卡片均质化”和“导入后落到星图时被左右三栏挤扁、重复出现两个星图”的体验断层。

---

## 一、现状诊断（基于代码实查）

1. **视觉层（大项 B 痛点）**
   - `src/app/globals.css` 中 `--accent` 与 `--cyan` 在浅/深两套主题里完全同色（浅色同为 `#2d5f8b`，深色同为 `#7aa6d6`），导致“复盘 / 概念 / 实盘 / 手册”四类信号视觉混成一团。
   - 浅色底 `#f7f6f3` 与白卡片 `#ffffff`、深色底 `#151619` 与卡片 `#1c1d22` 缺少景深层次与顶部高光边，全站卡片等重平铺，缺乏焦点（Focal Point）。
   - 财务数字与 KPI 指标未统一启用 `tabular-nums`，部分页面说明性副标题与括号注释密度偏高。

2. **星图落地页（新版大项 C 痛点）**
   - 在 `src/components/VaultWorkspace.tsx` 中，即使路由为 `/vault?view=graph&tour=1`，页面依然固定被切成三栏：左侧 256px 目录树 + 中间被挤窄的星图 + 右侧 328px 边栏（里面还嵌着一个 **252px 的重复迷你星图** 和大段空白反向链接列表）。
   - 在星图中点击任意节点会直接**硬切出星图**进入阅读页，打断探索脉络的连续感；连线均为生硬直线，外环节点密集时文字容易互相叠压。

## 二、大项 B：全新品牌深/浅色视觉 Token 与投研终端质感

### 1. 「曜石投研终端 × 温润投研纸本」双主题升级

保留深/浅双主题一键切换，但拉开 **3 层物理景深（画布底 → 悬浮面板 → 聚焦核心画布）**，并将四类核心资产赋予清晰的独立语义色：

| 视觉层级 / 语义 | 曜石暗色（Obsidian Terminal） | 投研纸本（Editorial Paper） | 用途 |
| :--- | :--- | :--- | :--- |
| **L0 画布底** `--bg` | `#0b0d12`（微径向冷光） | `#f2f1ec`（温润石膏纸） | 全站视口底色，托起卡片层次 |
| **L1 面板层** `--surface` | `#12151d` + 顶部 `1px` 微高光 | `#ffffff` + 柔和投影 | 常规卡片、列表、侧栏 |
| **L2 聚焦画布** `--hero-bg` | `#0e1118` + 建筑点阵 + 焦光 | `#faf9f5` + 建筑点阵 + 焦光 | 首页三线织脉画布、全息星图 |
| **复盘脉络** `--accent` | `#5b9bff`（冷静钴蓝） | `#235789`（矿石深蓝） | 主操作按钮、复盘时间轴节点 |
| **概念双链** `--cyan` | `#2dd4bf`（星图青绿） | `#0f766e`（松石青） | `#概念` 标签、双链连线、MCP 通道 |
| **实盘锚点** `--amber` | `#f5a623`（琥珀金） | `#b4690e`（焦糖金） | 交割买卖点、日期标尺、仓位预警 |
| **交易手册** `--emerald` | `#34d399`（翡翠绿） | `#15803d`（常青绿） | 凝练手册节点、验证通过态 |
| **风控警示** `--rose` | `#f46373`（珊瑚红） | `#be3144`（深玫红） | 回撤 MDD、知行偏离警示 |

### 2. 材质与细节精修（零花哨、偏 Linear × Bloomberg 质感）
- **毛玻璃顶栏（`.tl-shell-chrome`）**：启用 `backdrop-filter: blur(12px)` 与半透明底色 + `1px` 细光边，活动 Tab 改为干净的胶囊高光指示条。
- **卡片微质感（`.scifi-card` / `.tl-surface-elevated`）**：暗色模式加入 `inset 0 1px 0 rgba(255,255,255,0.045)` 金属顶边，悬停可点击卡片提供克制的边框提亮与微抬升。
- **量化数字排版**：全局 KPI、净值、盈亏比、日期统一 `font-variant-numeric: tabular-nums`，关键指标拉大字重对比（大号数字 + 极淡 10px 标签）。
- **全站文案减脂**：精简首页、账本、凝练、设置页的冗长副标题和括号备注，复杂解释收入 `title` Tooltip 或折叠 `?` 说明中，让核心视觉与主按钮直接呼吸。

## 三、新版大项 C：全画幅沉浸星图与交互体验重构

### 1. 空间重构：从“三栏挤压”改为“100% 全画幅星图 + 悬浮玻璃 HUD”

- **自动收折左右固定栏**：进入 `/vault?view=graph` 时默认隐藏左侧目录树和右侧固定检查器（彻底消除“大星图旁边套一个小星图”的违和感），左上角与右上角提供 1 键展开抽屉按钮，随时切回目录树或完整阅读模式。
- **点击节点 = 侧滑玻璃预览抽屉（不打断星图心流）**：
  - 单击任意节点后，星图镜头平滑聚焦高亮该节点及其 1 跳邻域，右侧滑出半透明预览抽屉（380px）：
    - 展示节点类型徽章、日期、正文摘要预览、命中 `#概念` 标签；
    - 若该日期有实盘记录，同步挂出 **当日净值 / 盈亏 / 交割单微卡片**；
    - 下方展示「相连节点胶囊」，点击任意邻居即可在星图内连续漫游；
    - 顶部主按钮 **`进入完整双链阅读 / 编辑 →`**，确认要精读时再切入双链文档视图。
- **向导态（`tour=1`）专属底部浮舱**：
  - 取代此前挤占右侧 328px 的向导卡片，改为悬浮在星图底部居中的极简玻璃操作条：
    - 左侧轻提示：`双链星图已织成（X 篇复盘 · Y 条双链）· 点击任意节点预览`
    - 右侧两枚直达主按钮：**「导入实盘交割单（防嘴盘） →」** 与 **「跳过实盘，选 AI / Agent 凝练 →」**。

### 2. 星图画布本体视觉升级（`src/components/ObsidianGraph.tsx`）
- **织脉入场动效**：从新手向导 Step 3 跳转进入星图时，四环轨道先淡入，节点按 `总览 → 概念/时间轴 → 复盘卡片` 顺次绽放（约 `0.6s`，支持 `prefers-reduced-motion` 自动关闭）。
- **曲线引力连线 & 聚焦压暗**：
  - 将生硬直线升级为带微弧度的贝塞尔曲线（Quadratic Bezier）；
  - 悬停或选中任意节点时，非关联节点柔和退隐（`opacity: 0.14`），关联连线亮起柔和能量脉冲流，一眼看清该笔复盘的完整因果脉络。
- **核心枢纽光晕 & 标签防叠压**：
  - 高连接度的 `#概念` 枢纽与 `交易手册` 节点增加柔和同心光环，一眼辨认你的高频交易基因；
  - 外环复盘节点按缩放比例智能隐藏拥挤标签，仅保留核心枢纽、当前选中节点与 1 跳邻居的高清晰文字标签（悬停即时浮现）。
- **星图内即时定位搜索**：左上浮舱输入框键入关键词或日期（如 `退潮`、`2025-05`），画布实时高亮所有命中节点，按回车直接聚焦首个匹配项。

## 五、开工前需确认的 3 个关键选择

1. **首次打开 App 的默认主题**
   - **选项 1（推荐）**：默认采用 **曜石暗色投研终端（Dark）**——开场织脉动画、全画幅发光星图与净值曲线的第一眼惊艳度最强，同时右上角一键切温润纸本亮色（Light）供长时间阅读复盘；
   - **选项 2**：保持当前默认 **温润纸本亮色（Light）**，只加深层次与质感对比。
2. **全画幅星图里单击节点的默认行为**
   - **选项 1（推荐）**：单击节点弹出 **右侧玻璃预览抽屉**（保持星图不消失，方便连续点不同节点逛星系），抽屉内点按钮或双击节点再进入完整文档阅读；
   - **选项 2**：保持单击直接切到完整文档阅读页。
3. **开发执行节奏**
   - **一次做完（Phase 1 + Phase 2 联调交付）**，还是 **先落地大项 B 看完视觉再改新版 C**？
