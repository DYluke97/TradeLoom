## 核心亮点一览

1. **多 Obsidian 双链知识库并行 & 4 环同心星轨图谱**：
   - 每个知识库独立隔离原始复盘（支持直接外挂本地已有 Obsidian 文件夹）、概念词典、**独立 A 股实盘账本**与交易手册存档；支持免配 API Key 一键体验独立沙盒示范库 `demo-sandbox`。
   - 全新 **4 环同心星轨双链图谱**（`中心总览 MOC → 主题星核环 → 年度档案环 → 月度时间索引环 → 复盘原件外环`），支持「骨架脉络 / 全量展开」一键切换与主题—时间跨维互链。
   - 左侧支持 **`年 → 月 → 日 → 复盘文档`** 四级穿透导航树；经 5 年 131 篇全粒度复盘压测，全量双链并发重建仅需 `~275ms`。
2. **9 大主流云端笔记连接器矩阵（`/sync`）**：
   - 原生支持 **滴答清单 / TickTick**（官方 MCP OAuth）、**Notion**（官方 MCP OAuth / Token）、**飞书文档**（扫码一键建应用 + 本机 `lark-cli` 双模）、**有道云笔记**（官方远程 MCP SSE）、**腾讯文档**（官方远程 MCP）、**腾讯 ima**（笔记本 + 知识库双通道 OpenAPI）、**Windows OneNote**（桌面版原生 COM 零配置直连）、**语雀**（Open API v2）、**印象笔记国内版**（官方 Skill RESTful API），并支持雪球、新浪财经博客、公众号等公开链接批量抓取与书签剪藏。
3. **A 股实盘投资账本 × 真实前复权日 K 线 `B/S` 买卖点复盘（`/ledger`）**：
   - 兼容 UTF-8 / GB18030 / UTF-16LE / TSV 券商交割单与日度净值导入，双阶段自动脱敏资金账号与股东代码；支持沪深北 A 股及可转债前复权日 K 线 `B/S` 节点标注、除权漂移自动刷新与沪深300等市场基准超额归因。
4. **逐字证据防幻觉 × 定性定量交叉证伪 × L1→L2 方法论演化（`/synthesize` & `/manuals`）**：
   - 服务端 `evidence_id` 逐字回填杜绝大模型幻觉；单次支持最多 300 篇样本预检，通过 L1 阶段手册 → L2 年度总纲（Map-Reduce）沉淀个人交易体系，内置规则生命周期标记、防“嘴盘”知行偏离审计榜与 `[实盘绩效存疑预警]`。
5. **纵深本地安全护栏与现代极简双主题工作台**：
   - 默认仅绑定 `127.0.0.1`，全局 API Middleware 拦截 DNS Rebinding 与跨站 CSRF，云端抓取逐跳 DNS 校验防私网 SSRF，删除卡片/手册/子库统一进入本地 `.trash/` 回收站。
   - 默认护眼暖白纸底 + 矿石板岩蓝主色，顶栏一键切换低反差柔炭深色模式。

## Windows 便携版 30 秒上手

1. 下载 `TradeLoom-v1.0.0-win-x64.zip` 并**完整解压到普通目录**（如桌面或 `D:\TradeLoom`）。
2. 双击 **`TradeLoom.exe`**，2~5 秒后自动拉起本地引擎并打开独立桌面窗口。
3. 所有个人数据均保存在解压目录下的 `workspace\` 文件夹中，升级新版本只需保留或复制 `workspace\` 即可无损迁移。
