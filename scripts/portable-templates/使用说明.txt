【一、30 秒快速启动（普通用户）】
1. 请先将整个压缩包完整解压到任意普通目录（例如 D:\TradeLoom，请勿在压缩软件内直接双击）。
2. 双击本目录下的「TradeLoom.exe」即可启动（内置独立 Node.js 运行时，无需安装任何依赖）。
3. 稍等 2~5 秒会自动弹出控制面板并拉起独立桌面窗口，同时右下角托盘会出现织脉图标：
   - 双击托盘图标：随时重新打开主窗口
   - 右键托盘图标：可直达实盘账本、打开本地 workspace 目录，或「退出并停止本地服务」

【二、首次体验推荐路径（3 分钟）】
1. 零配置沙盒体验：首次打开首页点击「一键进入体验示范库」，免配 API Key 即可在独立隔离的示范库中完整体验 4 环同心星轨双链图谱、A 股前复权 K 线 B/S 买卖点与示范交易手册（绝不污染你的主库）。
2. 导入个人数据：新建正式知识库后，可直接拖入 .md / .pdf / .docx / .txt 复盘文件，或前往「云端同步」直连飞书、Notion、有道云笔记、滴答清单、腾讯文档、腾讯 ima、桌面版 OneNote、语雀、印象笔记一键拉取；在「本库账本」拖入券商交割单 CSV（敏感账号列自动脱敏）。
3. 提炼交易手册：进入「系统设置」填入任意 OpenAI 兼容 API Key（DeepSeek / 硅基流动 / 本地 Ollama 等，仅存本机 workspace\config.json），前往「提炼方法论」生成 L1 阶段手册与 L2 年度总纲！

【三、技术向 / AI Agent 用户（Claude Code / Cursor / Antigravity 等）】
直接把解压目录路径发给你的 AI Agent，说「按 AGENT_START.md 帮我启动 TradeLoom」即可自动后台拉起并返回本地访问地址。

【四、数据备份与 Obsidian 联动】
你的全部知识库、复盘原文、实盘账本与交易手册均保存在同级目录「workspace\」中：
- 升级新版本时，只需保留或拷贝整个「workspace\」文件夹即可 100% 无损迁移。
- 可在桌面版 Obsidian 中打开「workspace\vault」（默认主库）或「workspace\vaults\<知识库ID>\vault」（子库），也支持创建知识库时直接挂载本地已有的 Obsidian 文件夹。
