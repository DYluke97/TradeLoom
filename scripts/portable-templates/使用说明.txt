【一、30 秒快速启动（普通用户）】
1. 请先将整个压缩包完整解压到任意目录（例如 D:\TradeLoom，请勿在压缩软件内直接双击）。
2. 双击本目录下的「TradeLoom.exe」即可启动（无需安装 Node.js 或任何依赖）。
3. 稍等 2~3 秒会自动弹出独立桌面窗口，同时电脑右下角任务栏托盘会出现织脉图标：
   - 双击托盘图标：随时重新打开主窗口
   - 右键托盘图标：可打开实盘账本、打开本地 workspace 目录，或「退出并停止本地服务」

【二、首次体验推荐路径（3 分钟）】
1. 体验「实盘账本」：点击顶部「实盘账本」→ 右上角「加载 A 股演示账本」，即可查看真实 A 股前复权 K 线、B/S 买卖节点标注与超额 Alpha 曲线；体验完随时可点「清理演示账本」，导入你自己的券商交割单 CSV 或每日手动记一笔。
2. 体验「双链知识库」：进入「双链知识库」可点「一键加载示例复盘库」体验全息星图与概念双链，也可直接拖入 .md / .txt / .docx / .pdf 复盘笔记，或用「云端粘贴」从飞书/Notion/雪球导入。
3. 配置大模型 API（可选）：进入「模型与 Skill」填入 DeepSeek / OpenAI / 硅基流动 / 本地 Ollama 的 Key（仅存本机 workspace\config.json），即可在「阶段提炼」生成带实盘定量核验的个人交易手册！

【三、技术向 / AI Agent 用户（Claude Code / Cursor / Antigravity 等）】
直接把本目录丢给你的 AI Agent，说「按 AGENT_START.md 帮我启动 TradeLoom」即可自动后台拉起并返回本地地址。

【四、数据备份与 Obsidian 联动】
你的全部复盘原文、双链知识库、实盘台账与交易手册均保存在同级目录「workspace\」中：
- 升级新版本时，只需保留或拷贝整个「workspace\」文件夹即可无缝迁移。
- 可在 Obsidian 中选择「打开本地仓库」直接指向「workspace\vault」。
