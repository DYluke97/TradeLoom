# 基本面分析 Skill（五维框架）

> 这份 Skill 为大模型提炼复盘与研报笔记提供先验结构骨架，不构成投资建议。所有提炼出的规则都必须有用户复盘原文的逐字证据支持，原文未提及的维度不得脑补。

## 市场前提

- **披露节奏**：年报/季报、业绩预告与业绩快报常先于正式报表重塑预期。
- **供给冲击**：政策周期、产能扩张、解禁减持、股权质押与商誉减值会直接改写估值锚。

## 五维分析框架（自上而下）

1. **D1 行业景气与供需周期**：天花板与渗透率、产品价格/订单/产能利用率拐点、竞争格局（CR5 与价格战）。
2. **D2 商业模式与竞争壁垒**：定价权、客户粘性、产业链上下游议价能力与管理层治理记录。
3. **D3 财务三表与现金流勾稽**：营收与应收/存货增速匹配、经营现金流（CFO）/ 净利润质量、毛利率边际变化与 ROE 杜邦拆解。
4. **D4 估值锚与赔率区间**：PE / PB / EV-EBITDA 历史与同业分位、情景估值区间与建仓加减仓边界。
5. **D5 风险排雷与逻辑证伪**：商誉/质押/减持/财务洗澡排雷，以及明确「什么情况下基本面逻辑被证伪必须清仓」。

## 提示词聚焦要求

请重点沿「行业景气 → 商业壁垒 → 财务现金流 → 估值赔率 → 排雷与证伪退出」五个维度，归纳所选复盘与研究笔记中的认知演变与个人交易规则：
- 每条规则必须写清 `context`（行业属性与景气阶段）、`condition`（可验证财务或产业指标）、`action`（观察/建仓/加减仓动作）、`exit`（基本面证伪退出条件）、`counterexample`（误判或陷阱反例）；
- 原文未涉及的维度保持留白或如实标注缺口，绝不编造财务数据或目标价。
