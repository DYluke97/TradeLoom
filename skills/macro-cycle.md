# 资源周期与仓位杠杆风控 Skill

> 本框架适用于大宗资源周期、高弹性顺周期板块及带杠杆/高仓位运作账户的复盘提炼。所有结论必须严格溯源至复盘原文，严禁编造数据。

## 五维审视骨架

1. **供需格局与资本开支周期**：辨析长期产能刚性/供给收缩主逻辑与短期宏观情绪、期货盘面扰动的主次关系。
2. **库存周期与价格-利润弹性**：观察现货/期货价格、显性库存拐点及高成本边际产能出清信号，警惕“高利润低市盈率”周期顶部陷阱。
3. **总仓位与融资担保比红线**：重点审视满仓单吊、融资加杠杆的触发边界、担保比例预警线及极端黑天鹅下的被动强平风险。
4. **净值回撤硬约束与抗洗盘平衡**：区分量化资金短期假破位洗盘与中期供需逻辑逆转，明确账户总净值回撤达阈值时的强制降仓/去杠杆条款。
5. **锚定效应与心态失衡审计**：重点捕捉“锚定历史最高净值急于翻本”、“死扛下跌却在黎明前恐慌割肉”等反复出现的知行偏离证据。

## 提示词聚焦要求

- 规则提炼须突出仓位上限、杠杆使用前提、回撤减仓阈值与供需证伪指标；
- 对跨季度被实盘大亏证伪的旧习惯（如逆势满融补仓）明确标记为 `deprecated`，对修正后的新风控规则标记为 `iterated`；
- 在 `discipline_audit` 中重点核查“口头强调风控去杠杆、实盘依然重仓硬扛”的重复违纪记录。
