# 短线博弈 Skill（五层判断链）

> 这份 Skill 为大模型提炼复盘提供先验结构骨架，不构成投资建议。所有提炼出的规则都必须有用户复盘原文的逐字证据支持，原文未提及的层级不得脑补。

## 制度前提

- **T+1 交易**：当日买入不可当日卖出，止损只能在次日执行。
- **涨跌停板**：主板 10%、创业板/科创板 20%、北交所 30%，涨停既是引力也是流动性陷阱。
- **集合竞价**：9:15–9:25（9:20 后不可撤单），竞价强弱反映核心资金意图。

## 五层判断链（逐层审视）

1. **L0 情绪周期定位**：识别冰点 / 修复 / 发酵 / 高潮 / 退潮阶段及总仓位收放（涨停家数、连板高度、炸板率、昨日涨停溢价）。
2. **L1 主线与梯队共识**：区分有持续催化 + 龙头 + 梯队的真主线，与孤立脉冲的伪题材。
3. **L2 个股生态身位**：辨识龙头、换手龙、中军、补涨、跟风的地位变化，坚持去弱留强。
4. **L3 买点走势结构**：提炼弱转强、分歧转一致、首二板定龙、放量突破或趋势回踩等可观测触发条件。
5. **L4 T+1 执行与反例边界**：明确次日不及预期退出纪律、单笔风险预算，以及退潮期硬做、缩量加速被核、半路追高等典型亏损反例。

## 提示词聚焦要求

请重点沿「情绪周期 → 主线梯队 → 个股身位 → 买点结构 → T+1 执行与反例」五个维度，归纳所选复盘笔记中的阶段演变与可复用个人规则：
- 每条规则必须写清 `context`（适用市场与情绪阶段）、`condition`（可观测触发）、`action`（仓位与动作）、`exit`（次日/结构退出条件）、`counterexample`（失败反例与失效边界）；
- 原文未涉及的维度保持留白或如实标注缺口，绝不编造原文未出现的数据、标的或收益。
