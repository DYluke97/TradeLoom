# 趋势波段与盈亏比管理 Skill

> 本框架适用于跨市场（美港股、A 股中线趋势、商品期货、Crypto）主观趋势与波段复盘提炼。所有规则与审计结论必须有原文逐字证据支持，未提及维度绝不脑补。

## 五维审视骨架

1. **市场状态过滤（Market Regime）**：区分单边趋势顺风期与宽幅震荡磨损期，识别无趋势环境下的频繁止损损耗。
2. **右侧结构与入场触发**：提炼均线多头排列、底部箱体放量突破、关键支撑缩量回踩或业绩/事件缺口延续等可量化信号。
3. **波动率头寸与风险预算（R-Multiple）**：明确单笔最大允许亏损占净值比例（如 1R = 净值 1%~2%）、初始止损距离与分批建仓条件，杜绝浮亏加仓。
4. **移动止盈与假突破证伪**：区分逻辑未变正常回调与关键趋势线/成交量结构破坏，明确保本止损上移与右侧分批兑现规则。
5. **盈亏同源认知与高频违纪**：重点排查“截断利润却让亏损奔跑”、过早猜顶摸底、震荡市重仓追突破等知行偏离行为。

## 提示词聚焦要求

- 每条规则必须写清适用市场状态、入场条件、头寸管理动作、证伪/止盈退出边界与典型失败反例；
- 若前后阶段规则发生自我修正（如从固定百分比止损升级为关键结构止损），标注 `lifecycle: "iterated"` 或 `"deprecated"` 并写明冲突演进原因；
- 严格对照作者立下的纪律与实盘真实亏损记录，如实提炼 `discipline_audit`（知行偏离病灶）。
